**Solaria Bay: Sun & Syndicate** — an original real-time 3D WebGL open-world crime action game powered by vendored Three.js r169, playable completely offline in a desktop browser. Explore seven sun-soaked coastal districts and Starlight Isle across the Solaria Arch Bridge on foot and behind the wheel of 18 sculpted vehicles, outrun a 5-star SBPD tactical dispatch and AIR-1 spotlight helicopter pursuit system, complete 10 multi-stage story missions and 24 open-world activities with 8 weapons and 3 Crew Favours, customize vehicles at Solaria Customs, tune into 4 procedural Web Audio FM radio stations, and save progress across 3 persistent localStorage slots.

## Run it

```sh
node serve.ts
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
