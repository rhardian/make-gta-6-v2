**Solaria Bay: Sun & Syndicate** — an original 3D open-world crime action game playable offline in a desktop browser. Explore the sun-soaked coastal city of Solaria Bay on foot and behind the wheel, hijack and drift sports cars and speedboats, outrun a 5-star VCPD police and helicopter pursuit system, battle rival crews across a multi-act story campaign, navigate with a live GPS minimap radar, tune into procedural synthwave radio stations, and save your progress across slots.

## Run it

```sh
node serve.ts
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
